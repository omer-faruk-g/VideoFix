# VideoFix

Claude Code skill built from five Claude Code videos/shorts: context and limit habits (defers to ClaudeLimit/Graphify), a public-API reuse checklist, a ship gate (browser check, security pass, current docs, read-only DB tools, permitted design tokens) and a no-unmeasured-claims rule.

Install: copy this folder to `~/.claude/skills/videofix/`.

Check (read-only): `python scripts/check.py --project <dir>`

Tests: `python -m unittest discover -s tests`

Video summaries (Turkish): `references/sources.md`
